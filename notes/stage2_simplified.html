动作条件预测

验证：先训练并冻结一个显式动作预测器，再把未来预测误差回传到 DiT，能否比仅做当前特征对齐更好地改善机器人轨迹？

保留 V-JEPA encoder保留 AggregatorGRU 替代 RSSM首轮只做一步预测

本版同时改变网络与目标：从预测 RSSM posterior，改为预测 Aggregator embedding。它是最小预测实验，不能单凭结果判断 RSSM 或随机状态是否必要。Aggregator 不使用 V-JEPA 权重初始化。

图示阶段 C；绿色模块冻结但保留输入梯度，橙色为损失。B、D 为线性层。两处 G 是同一组权重。

e* 是 GT 特征，ê 是当前估计，ẽ 是未来预测；三者在同一 embedding 空间。h 是 GRU 内部记忆，不直接与 e* 对齐。“语义”来自预训练视觉特征，不保证已保留机器人位置与动作信息。

02 · Role of Each Step

每一步做什么

步骤作用要排除的问题
V-JEPA → G定义固定 GT embedding；两路共享 G目标近似常数，或丢失位置与位移
H → P → G从带噪 DiT hidden 估计当前 embedding读出误差被误认为动力学误差
B → GRU → D由当前估计和下一动作显式预测未来 embedding只复制当前特征，或忽略动作
Lalign当前估计 êₜ 对齐当前 GT e*ₜ当前读出偏离目标空间
Lpred未来预测 ẽₜ₊₁ 对齐未来 GT e*ₜ₊₁仅增加对齐监督，却未检验预测的价值
Lalign = meanₜ d(êₜ, sg[e*ₜ])
Lpred = meanₜ d(D(GRU(MLP(aₜ₊₁), B(êₜ))), sg[e*ₜ₊₁])

首轮沿用 17 对：t=3…19，预测并比较 t+1=4…20。每组 4 帧，aₜ₊₁ 是对应动作片段，按时间顺序输入；对齐项也用 t=3…19。最后一组仍受 LFM 训练。

固定目标：冻结 V-JEPA 与 G；d 使用固定训练集统计标准化后的 MSE。不同 GT 目标使常数输出无法把对齐误差降为零，但预测器仍可能退化为均值预测。目标方差和运动信息都要检查。

03 · Training Order

先学预测，再接入 DiT

首轮复用现有 Teacher 中已训练的 G 并始终冻结；这依赖已有 checkpoint，不意味着免去了原 Teacher 的训练成本。若其运动信息不足，先停下排查表示。

PHASE A · PREDICTOR

学习干净特征的转移

把图中的 êₜ 换成 e*ₜ，只训练 B、GRU、D，优化 Lpred。先检查一步预测；通过后可尝试 2、4 步。

输出：冻结的动作预测器
→
PHASE B · ADAPTER

校准当前特征读出

冻结 DiT、G、预测器，只训练 P。先优化 Lalign，再加入 Lpred。P 不混合时间组，并输入噪声量 σ。

输出：冻结的 Adapter
→
PHASE C · DIT

比较对齐与预测的收益

冻结整个辅助分支，仅更新 DiT。两项辅助损失均穿过冻结模块回传；推理移除辅助分支。

输出：生成视频与轨迹评测

首轮可只在低噪声区间施加辅助损失，B/C 使用同一区间；LFM 覆盖完整噪声范围。多步预测时继续传递 h 和动作，起点后不再读 H 或 GT。单个 embedding 若缺少速度，可另测短历史输入。

因果边界：Wan hidden 已混合未来信息；完整视频编码得到的 V-JEPA 特征也可能如此。首轮检验预测约束的生成收益。若要证明仅凭过去预测未来，需额外限制两路起点的未来输入，不能仅靠 GRU 的递推结构。

推进条件：固定目标保留运动信息、预测器优于简单基线、接入 DiT 后轨迹稳定改善。之后才在一致目标和训练预算下比较 GRU 与 RSSM。
